# HADIRIN — Digital Attendance

Absensi QR mahasiswa berbasis HTML, CSS, JavaScript, Google Apps Script, dan Google Sheets.

Database: tab `Data Mahasiswa` dan `Presensi`.
Hosting: GitHub Pages.
Kamera membutuhkan HTTPS dan izin pengguna.
Audio pembukaan: `assets/audio/welcome.mp3`.

Apps Script URL sudah dikonfigurasi di `js/config.js`.
